# 数据集说明

本目录按 `train/test` 和 `nailong/naiwa/other` 组织。

- `nailong`：奶龙官方形象、漫画、动画宣传图与壁纸。
- `naiwa`：这里按当前网络梗“奶蛙 / 大笑奶龙 / 变异奶龙”收集，而不是普通婴儿或普通青蛙。训练图覆盖多种独立姿态、场景和艺术风格，不再使用同一段视频的连续抽帧。
- `other`：普通照片与其他卡通形象；其中包含青蛙、绿色恐龙和黄色袋鼠等相似负样本，避免模型只按颜色或轮廓判断。

2026-10-17 收集后，训练集包含 12 张奶龙、13 张奶蛙、12 张静态其他图片和 1 个黄色袋鼠 GIF，测试集每类 3 张。训练时 GIF 会固定进入训练分区，每轮随机抽帧并提高采样权重；原有的 `test/nailong/image.png` 保持不变，并计入奶龙的 3 张测试图。

第三方图片和角色形象仅用于本地训练、测试与研究；权利归各原权利人所有。逐图来源见 `SOURCES.csv`。
